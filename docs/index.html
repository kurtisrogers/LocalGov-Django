LocalGov Django

A complete Django port of LocalGov Drupal — the open source publishing platform built by UK councils for better digital services.

View on GitHub LocalGov Drupal docs

Built for developers

LocalGov Django replicates the LocalGov Drupal distribution using Django best practices — modular apps, class-based views, comprehensive tests, and the exact same LocalGov Base theme styling.

Features

Services

Service landing pages, sub-landing pages, service pages, and service status updates.

Directories

Searchable directory channels with facets, organisations, venues, and pages.

Guides & Step by step

Multi-page guides and sequential step-by-step processes with navigation.

News & Events

Newsrooms with featured articles, categories, and event listings.

Subsites & Alerts

Subsite overviews with child pages and site-wide alert banners.

Sitewide search

Search across all content types from a single search interface.

Quick start

git clone https://github.com/kurtisrogers/LocalGov-Django.git
cd LocalGov-Django
pip install -r requirements.txt
python manage.py migrate
python manage.py load_sample_content
python manage.py runserver

Visit http://localhost:8000 to see the demo site with sample council content.

Testing

Unit tests and Playwright BDD scenarios are included:

pytest                    # Run all tests
pytest tests/ -k "not bdd"  # Unit tests only
pytest tests/bdd/           # Playwright BDD tests

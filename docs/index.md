# LocalGov Django

LocalGov Django is an open source publishing platform for UK local government — a Django implementation of the [LocalGov Drupal](https://localgovdrupal.org/) feature set, using the same LocalGov Base theme styling.

</div>

Here you can find all the documentation for LocalGov Django, from installation to configuration, theming and using the content types.

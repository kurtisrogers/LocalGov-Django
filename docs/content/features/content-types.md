# Content types

A LocalGov Django site has a number of content types, each suited to a particular purpose.

## Directory channel

A page where users are presented with a searchable or filterable list of directory items.

Directory items can be directory pages, directory organisations, directory venues, or custom types.

[Directories documentation →](directories.md)

## Directory organisation

An organisation to show in a directory, e.g. a library or a school.

## Directory venue

A venue with a location to show in a directory, e.g. a sports facility or a park.

## Event

An event to appear in the events listing.

## Service landing page

The top level page for a service.

[Services documentation →](services.md)

## Service page

The basic page that can be placed in a service, and on a service sub-landing page.

## Service status

Shows updates about the status of a service.

## Service sub-landing page

Shows detail and links to specific pages within a service.

## Subsite overview

The landing page for a subsite.

## Subsite page

A child page in a subsite. Requires a subsite overview.

## Step by step overview

The main page for a step-by-step process.

## Step by step page

A single step in a step-by-step process. Requires a step by step overview.

## Guide overview

The main page for a collection of connected pages.

## Guide page

A single page in a guide. Requires a guide overview.

## Newsroom

A page for listing and featuring news articles.

[News documentation →](news.md)

## News article

A stand-alone news article that may also appear in a news listing page.

## Alert banner

A site-wide or page-specific alert shown to citizens.

[Alert banners documentation →](alert-banners.md)
